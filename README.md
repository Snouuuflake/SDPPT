# SDPPT: Stream Deck Power Point

Pair of CMD/PowerShell scripts for controlling PowerPoint presentations from a Stream Deck, even if the presentation is unfocused.

CMD scripts can be run from a "Open" key- they run the PowerShell scripts.

---

Par de scripts de CMD/Powershell para controlas presentaciones PowerPoint desde un Stream Deck, aunque la presentación no esté enfocada.

Los scripts de CMD se pueden ejecutar con una tecla "Open"- ellos ejecutan los scripts de Powershell
